这是什么

用一台电脑的键盘和鼠标控制局域网里的其他 Windows 或 Linux 电脑，并可以同步剪贴板。左上角的版本号来自程序编译时的版本。Windows 双击托盘图标打开这个窗口。Linux 托盘没有双击事件，单击图标打开，右键是菜单。

两种模式

  • 键鼠主机：物理键鼠在这台电脑上。首页会显示屏幕位置，把连上的电脑拖到主机的上下左右或四个角，鼠标移到对应的边或角就会切过去。
  • 被控端：接受主机的键鼠。不显示屏幕位置。默认就是被控端。

怎么连上

  • 两台电脑选同一网段的网卡。以太网和 Wi-Fi 都会列出，有以太网时默认用以太网。
  • 端口在「设置」里，不改则是 24900。两边必须相同，并在防火墙上放行该端口的 UDP 和 TCP。
  • 主机搜索时可以同时连多台。键鼠数据走 TLS 加密。被控端会询问是否允许这台键鼠主机控制：信任后记住对方证书，取消则拒绝。证书变了会再问一次。
  • 计算机名只在本软件里使用，不会修改 Windows 或 Linux 的计算机名。布局里的名字要和对方的计算机名一致。

快捷键

  • 锁定屏幕：ScrollLock
  • 切回键鼠主机：Ctrl+Alt+Home
  • 暂停或恢复共享：Ctrl+Alt+Pause

可以在「设置」里改。边缘切换的延迟和死区也在设置里。

日志

「日志」页显示内核最近写入的内容。Windows 默认在 %APPDATA%\Cross-SystemConnect\Cross-SystemConnect.log。Linux 默认在 ~/.local/state/cross-systemconnect/Cross-SystemConnect.log。改路径后要重新启动才会写入新文件。

键鼠主机请求控制

信任后记住这台主机的证书，下次不再询问。取消则拒绝本次控制。证书变了会再问一次。
