## 1. 背景

开发者和办公用户常常同时使用一台 Windows 电脑和一台 Linux 电脑，桌上放两套键盘鼠标，文件靠 U 盘、网盘或聊天软件传来传去。Cross-SystemConnect（下称 CSC）让一套键盘鼠标控制多台电脑，并在电脑之间同步剪贴板、用复制粘贴互传文件。

典型连接方式：两台电脑各自通过 Wi-Fi 上网，另用一根网线直连（或 USB 网卡、USB4 直连）专门给 CSC 用。直连网卡只配 IP 和掩码，不配网关和 DNS，上网流量不走直连线。

```
            Wi-Fi（各自上网）
   ┌──────────────┐          ┌──────────────┐
   │  Windows PC  │  网线直连 │   Linux PC   │
   │ 192.168.100.1│◄────────►│192.168.100.2 │
   │ （键鼠在此）  │  CSC 通信 │              │
   └──────────────┘          └──────────────┘
```

## 2. 目标用户

| 用户 | 场景 | 关注点 |
|---|---|---|
| 双系统开发者 | Windows 写文档/调试工具 + Linux 编译/嵌入式开发 | 切换手感、低延迟、文件快速互传 |
| 办公用户 | 一台主力机 + 一台副机 | 开机即用、无需操作、剪贴板互通 |
| 多机桌面用户 | 一台主机 + 2–8 台被控端（上下左右与四角） | 布局直观、被控端之间互传 |

## 3. 产品目标

1. 一套键鼠无感地控制多台 Windows / Linux 电脑（Linux 支持 X11 会话与 GNOME Wayland 会话，包括 Ubuntu 默认会话），手感尽量接近“同一台电脑的多块扩展屏”（固有差距见 §10）。
2. 剪贴板与文件粘贴在后台自动完成，用户**不需要点击「发送」或「接收」**。
3. 安全：只有在两端都主动开启「允许新配对」、主机显示的配对码被被控端正确输入、并且用户把新电脑摆进布局之后，对端才能收到键盘输入和剪贴板。
4. 键鼠延迟接近本机：输入到注入 P50 < 1 ms、P99 < 2 ms。

## 4. 术语

| 术语 | 含义 |
|---|---|
| 主机 / 服务端（server） | 物理键鼠所在的电脑，负责捕获输入、判断切换 |
| 被控端 / 客户端（client） | 被控制的电脑，负责注入输入 |
| 活动屏幕 | 当前正在接收键鼠输入的电脑 |
| 屏幕布局 | 主机在中间，已配对的电脑放在上下左右或四个角 |
| 配对 | 两端都在「允许新配对」时间窗（默认 2 分钟）内时，主机显示 6 位配对码，被控端输入该码，两端确认后按 `device_id + 证书指纹` 互认 |
| 允许新配对 | 用户在设备页/托盘/向导中主动开启的限时窗口；不在窗口内的配对请求一律拒绝 |
| 暂停共享 | 临时停止键鼠切换、剪贴板与文件共享，连接保持；被控端本地紧急暂停热键效果相同 |
| 共享剪贴板（文件） | 复制文件时只把条目清单告诉主机，不传内容；在另一台电脑的文件管理器或桌面粘贴时才传输，存到该窗口当前目录 |
| 虚拟文件 / 占位 | Linux 粘贴时由 CSC 提供给系统的文件或文件夹（占位内含随机令牌），用来从系统得知粘贴的目录 |
| 中转 | 被控端之间的传输由主机按顺序转发，不落盘 |
| 兜底保存目录 | 拿不到文件管理器当前目录、托盘粘贴时的存放目录，默认桌面 |
| core / ui | `Cross-SystemConnect-core` 无界面内核；`Cross-SystemConnect` 托盘与设置窗 |

## 5. 功能需求

| 编号 | 功能 | 说明 | 优先级 |
|---|---|---|---|
| F1 | 键鼠共享 | 边缘切换：光标到达有邻居的边或角后继续往外推过 `switch.edge_push_px`（默认 8 像素原始位移）才切换，多推的位移带到目标屏继续移动；读不到原始位移时退回“碰边即切”。到边检测由指针事件驱动，无定时轮询。键盘跟随、滚轮（含水平，1/120 格高精度）、鼠标按键（含侧键）。离开由被控端判定（`EDGE_HIT`）。指针速度、光标、滚动、连发一致性见 F34 | P0 |
| F2 | 屏幕布局与多显示器 | 主机首页拖动方块摆放（上下左右与四角，间距 5 像素，吸附空位）；新配对的电脑先放在“未摆放”区，由用户拖入；按每块显示器的外露边判断到边，支持负坐标和混合 DPI；一条边由多块显示器组成时按“跳过空档、首尾相接”的比例映射。按显示器摆放与偏移对齐列入 M8（TBD） | P0 |
| F3 | 文本剪贴板 | UTF-8 双向同步，上限 `clipboard.max_inline_mb` 1–15 MB（默认 15）。变化检测事件驱动；≤ 64 KiB 直接推送，更大的在粘贴时才拉取；切屏和离开被控端前都会刷新，不阻塞切换。发送时机 `clipboard.push_mode`：`immediate`（默认）/ `on_switch`（只发给切过去的电脑）。只发给已配对且在布局中的对端；带密码管理器标记的内容不同步；暂停共享时不同步 | P0 |
| F4 | 图片剪贴板 | 截图/复制的图片以 PNG 传输，粘贴时才拉取；上限同 F3；同时有文字和图片时按文字处理 | P1 |
| F5 | 文件复制粘贴 | 复制文件/文件夹时不传输；在另一台电脑的**文件管理器窗口或桌面**粘贴时，文件存到**该窗口当前显示的目录**（桌面即桌面目录），拿不到当前目录时才存到兜底保存目录。Windows：拦截文件管理器/桌面里的 `Ctrl+V`，用 `IShellWindows` 取当前目录；Linux（X11 与 Wayland）：焦点在文件管理器/桌面时 CSC 临时提供指向占位的文件剪贴板（同时保留原文字内容），文件管理器自己完成粘贴后用 inotify 定位目录，因此 `Ctrl+V` 和右键「粘贴」都可用。其他窗口里的粘贴照常交给系统。任何电脑上的新复制使旧的文件记录失效。托盘菜单提供「粘贴其他电脑复制的文件到这里」（存到兜底目录） | P0 |
| F6 | 文件拖拽 | **已取消**。跨屏拖文件已移除；电脑之间传文件只用 F5 复制粘贴（`Ctrl+C`/`Ctrl+V` 与托盘粘贴）。相关协议位与消息保留未用，见[架构设计](架构设计.md) §4.6 | — |
| F7 | 快捷键与锁屏协调 | 回到主机 `Ctrl+Alt+/`；所有电脑一起锁屏 `Ctrl+Alt+Shift+L`（避开 IDE 的 `Ctrl+Alt+L`；可改为 `Win+L`，Windows 主机上会先锁本机再联动）。联动只针对用户主动锁屏和主机闲置锁屏，被控端闲置锁屏不联动；用户在任一电脑活动时其他电脑不熄屏、不闲置锁屏（`power.keep_peers_awake`）；3 s 内去重。AltGr 布局下 `AltGr+键` 不触发 `Ctrl+Alt` 热键 | P1 |
| F8 | 断线重连与不卡键 | 断开或网卡恢复后自动重连；断开时键鼠回主机；切换、断线、锁屏时被控端释放所有按下的键和鼠标按钮；被控期间 1.5 s 无数据即判定断开，有按下的键或按钮时缩短为 500 ms | P0 |
| F9 | 传输进度与保存位置 | 只在接收端弹出进度窗：进度、速度、剩余时间、取消、打开位置、实际存放位置。粘贴存到文件管理器当前目录；拿不到时存到兜底保存目录（默认桌面，仅配置文件可改 `file_transfer.receive_dir`） | P2 |
| F10 | 加密与配对 | 只用 TLS 1.3，双向 Ed25519 自签名证书；配对需两端都开启「允许新配对」（默认 2 分钟）；配对码用承诺-揭示方式生成（防中间人碰撞），主机显示、被控端**输入**；指纹变化时红色警告；新配对的电脑不自动进布局；未配对连接不收任何输入和剪贴板 | P0 |
| F11 | 被控端互传 | 被控端之间的粘贴经主机中转，不落盘 | P1 |
| F12 | 重名处理 | 保存位置已有同名项时，在进度窗里选择跳过 / 保留两者（「原名 (1)」「(2)」）/ 替换；替换先写临时文件，校验通过才覆盖 | P1 |
| F13 | 日志 | 默认写文件、级别 info，路径默认程序目录 `log.txt`（不可写时退到用户目录）；单文件 1 MB 时转存为 `log.1.txt`。级别、路径、开关修改后立即生效 | P2 |
| F14 | 首次运行与角色 | 首次运行向导选择本机是否为主机；两端都是主机时提示角色冲突、不建立会话 | P1 |
| F15 | 已配对设备管理 | 设置页列出已配对设备，可移除（对端重装后可重新配对） | P1 |
| F16 | 网络端口配置 | 只在选中网卡（未选时只在私有/链路本地地址）上监听。键鼠控制连接与文件数据连接使用**不同端口**：设置页「网络」可改控制端口（TCP，默认 24900）、数据端口（TCP，默认 24901）、发现端口（UDP，默认 24900），范围 1024–65535。控制端口与数据端口不能相同；被其他程序占用的端口不能保存（UI 显示错误并禁止保存）。发现端口所有电脑必须相同，可与控制端口数值相同（UDP 与 TCP 互不冲突）；控制/数据端口各电脑可以不同，主机按对端在发现报文和握手中通告的端口连接。修改后自动重新监听并重连，无需重启。配置文件里端口相同或超出范围时，内核不监听网络并显示“网络配置无效”（`config_invalid`） | P1 |
| F17 | 主机休眠/重启/断网 | 被控端本地键鼠任何时候都可用（CSC 从不抓取被控端的本地输入）。主机休眠、关机、重启前通知被控端并释放按键；主机唤醒后立即重建网络并重连；被控端托盘显示主机状态（已连接 / 主机休眠 / 主机失联 / 重连中） | P0 |
| F18 | 安全桌面 | v2 不支持在 Windows 安全桌面（锁屏、登录、UAC）上注入。被控端进入安全桌面时上报 `secure_desktop`，主机立即收回键鼠并显示该状态，状态解除前不切到这台电脑。可选的 Windows 服务（SYSTEM）助手放到 M7，是否实现 TBD | P1 |
| F19 | 键盘布局与输入法 | 按物理键位（USB HID Usage）转发，不转发字符；字符由被控端自己的键盘布局和输入法产生。修饰键一一对应（Win ↔ Super、Ctrl、Alt、Shift，左右区分）；可选键位重映射 | P0 |
| F20 | 锁定键同步 | 切换时以主机为准同步 CapsLock / NumLock / ScrollLock；控制远端时改变的锁定状态回到主机后同步给主机；可关闭 | P1 |
| F21 | 版本协商与更新 | `HELLO` 携带软件版本和协议版本范围，选最高共同协议版本；无共同版本时两端提示双方版本。最低支持协议 2（软件 0.2.0）。更新检查默认关闭，只提供手动「检查更新」，不自动下载安装 | P1 |
| F22 | 切换辅助 | 按住指定修饰键时不切换；「锁定在当前屏幕」开关与热键（默认 `Ctrl+Alt+Shift+K`）；前台为全屏程序时不按边缘切换（默认开）；角落死区（默认 10 像素） | P1 |
| F23 | 富文本剪贴板 | 同步纯文本、HTML、RTF，按需拉取；纯文本始终作为后备。同时有文件和文字时按文件处理；同时有文字和图片时按文字处理（附带 HTML/RTF） | P2 |
| F24 | 文件传输细节 | 断线后 30 分钟内自动断点续传（续传前核对发送方身份）；大量小文件打包传输；保留修改时间（Linux 间保留权限位，存到桌面时去掉可执行位）；Windows 接收的文件带来源标记（Mark-of-the-Web）；传输前检查剩余空间与文件系统单文件上限；跨系统文件名自动调整（非法字符、保留名、大小写冲突、长路径），并在进度窗列出被改名的项 | P1 |
| F25 | 系统通知 | 连接、断开、配对请求、传输完成/失败、错误等系统通知，各类可在设置里开关；同类通知 5 秒内只弹一次 | P2 |
| F26 | 多语言 | 界面、托盘、通知支持简体中文与英文；设置里选择「跟随系统 / 简体中文 / English」，立即生效 | P2 |
| F27 | 网络环境 | 手动添加对端地址（IPv4、IPv6、主机名，可跨网段、经 VPN）；IPv6 监听（私有与链路本地地址）；网卡「自动」模式下有线断开时自动改用其他网卡重连，不需要重新配对；自动模式排除公用网络和不在信任列表中的 Wi-Fi | P1 |
| F28 | 健壮性与诊断 | 界面监护内核，异常退出自动重启；崩溃信息落盘；内存自检与上限；一键导出诊断包（不含私钥、portal 令牌和剪贴板内容；崩溃转储默认不含，需用户勾选） | P1 |
| F29 | 隐私与安全基线 | 任何日志级别都不记录按键内容、剪贴板内容、文件内容；无遥测；发布包签名；更新清单签名验证；私钥文件仅本用户可读（可选系统密钥库保护）；设置界面防脚本注入（纯文本渲染、严格 CSP、按窗口限制可调用的方法）；管理员模式下普通进程不能操纵内核；未认证连接限流、消息方向检查；提供杀毒软件/EDR 误报处理与白名单说明；提供隐私声明 | P0 |
| F30 | 卸载与数据清理 | 卸载时移除程序、自启项、防火墙规则；可选择是否删除配置、证书、配对记录、日志；提供命令行卸载与应用内「清除所有数据」 | P1 |
| F31 | 性能测量方法 | 内置测量模式：时钟同步后测键鼠单向延迟 P50/P99、文件吞吐和小文件速率，输出 CSV；定义标准测试环境与验收流程 | P0 |
| F32 | Wayland 会话 | 支持 GNOME 46+ Wayland（Ubuntu 24.04 / 25.10 / 26.04 默认会话）：主机用 InputCapture portal（指针屏障）捕获，被控端用 RemoteDesktop portal + libei 注入（首次需在被控端本地允许一次，之后用恢复令牌免弹窗），剪贴板用 RemoteDesktop Clipboard 接口；焦点/全屏/文件管理器识别、本机态热键、光标隐藏由随包的 GNOME Shell 扩展提供（有 GlobalShortcuts portal 时用 portal 注册热键）；KDE Plasma 6 尽力而为，wlroots 系不支持 | P0 |
| F33 | 共享控制与托盘绿点 | 托盘「暂停共享」；被控端本地紧急暂停热键 `Ctrl+Alt+Shift+P`（主机不转发该组合）；已连接时托盘图标右下角绿点常亮，被控中仅被控端绿点闪烁；威胁模型明确“已配对主机等于拥有被控端键鼠” | P0 |
| F34 | 指针与输入一致性 | 位移按主机加速后的逻辑像素传输，按两端显示器缩放换算使物理速度一致，每台对端可设速度系数；控制远端时隐藏主机光标，被控端非活动时隐藏其光标；滚轮 1/120 格高精度；按键连发只由被控端产生；回到主机时光标出现在映射位置 | P0 |

## 7. 范围

### 7.1 支持平台

- Windows 10/11（x86_64）
- Linux x86_64：
  - **GNOME 46+ Wayland 会话**：Ubuntu 24.04 LTS（GNOME 46，默认 Wayland）、Ubuntu 25.10（GNOME 49）、Ubuntu 26.04 LTS（GNOME 50）。Ubuntu 自 25.10 起已移除 GNOME 的 Xorg 会话（Ubuntu 官方公告），26.04 的 GNOME 只有 Wayland，因此 Wayland 是 Ubuntu 上的主路径。
  - **X11 会话**：Deepin、Ubuntu 24.04 的“Ubuntu on Xorg”、Xfce/MATE/Cinnamon 等仍提供 X11 的桌面（已验证列表 TBD）。
  - KDE Plasma 6 Wayland：尽力而为（文件粘贴只用托盘，状态 TBD）；wlroots 系（Sway、Hyprland）不支持。

### 7.2 不做（v2）

- 公网穿透（只做局域网发现与直连）。
- 音频、屏幕画面共享。
- wlroots 系 Wayland 合成器（无 InputCapture portal）。
- macOS（架构上预留）。
- UAC / 登录界面 / 锁屏等 Windows 安全桌面上的控制（v2 显示 `secure_desktop` 状态并收回键鼠；服务助手计划 M7，TBD）。
- 跨电脑拖动窗口、跨电脑拖文字/图片/链接/文件（文件用复制粘贴，见 F5、§10）。
- 自动下载安装更新（只提供手动检查）。
- 发现跨网段的电脑和 IPv6 自动发现（跨网段、IPv6 用手动地址）。
- 遥测与使用统计。
- 与 v1.x 互通（协议 v2 不兼容 v1）。

## 9. 已知限制

| 项目 | 说明 |
|---|---|
| 管理员窗口（Windows） | 非提权进程无法向管理员窗口注入，主机的低级钩子也收不到发往管理员窗口的输入；可选“以管理员权限运行”自启 |
| Linux 运行库 | X11：缺 `libx11-6`/`libxtst6` 时指针不动；缺 `libxi6` 时退回“碰边即切”。Wayland：需要 xdg-desktop-portal 与 xdg-desktop-portal-gnome；Shell 扩展未启用时文件粘贴只能用托盘、全屏检测失效 |
| Wayland 授权 | 被控端首次需要本地点一次“允许远程交互”；授权失效后需再次本地确认；GNOME 顶栏会常驻远程桌面指示 |
| 游戏/全屏 3D 程序 | 被控端前台隐藏或限制光标时改用相对移动，暂停边缘离开，只能用热键回主机 |
| 杀毒软件 | 键盘钩子可能被误报；发布包签名以降低误报，用户手册提供白名单说明 |
| 键盘布局不同 | 按键位转发，两端布局不同时同一个键打出的字符按被控端布局 |
| Linux 粘贴期间的剪贴板 | 焦点在文件管理器且有其他电脑的文件记录时，本机剪贴板临时换成占位（文字内容保留，图片等其他格式暂不可用），焦点离开即恢复 |
| Windows 右键粘贴 | 不触发传输（用 `Ctrl+V` 或托盘）；虚拟文件剪贴板方案列入 M8 |
| X11 被控端滚动 | XTest 只能整格滚动，触摸板平滑滚动到 X11 被控端会变成逐格 |

## 10. 固有限制（与“同一台电脑多块扩展屏”的差距）

| 差距 | 原因 | 缓解 |
|---|---|---|
| 窗口不能拖到另一台电脑，也不能横跨两台电脑 | 每台电脑各自的窗口系统 | 无 |
| 键盘跟随活动屏幕：不能指针停在 B、键盘输入到 A 的窗口 | 键鼠作为一个整体切换 | 「锁定在当前屏幕」 |
| 文件不能跨屏拖放，只能复制粘贴 | 跨屏拖拽已取消 | 在源端复制，到目标端文件管理器/桌面 `Ctrl+V` 或托盘粘贴（F5） |
| 剪贴板不是同一个：大内容在粘贴时才传输，粘贴可能稍等 | 跨网络 | 事件驱动、切换前刷新、按需拉取 |
| `Ctrl+Alt+Del`、UAC、登录界面只能本机操作；触摸板多指手势由主机系统处理，不转发 | 系统安全设计 | `secure_desktop` 状态与自动收回键鼠 |
| 键盘布局与输入法各自独立 | 按键位转发 | 两端设相同布局 |
| 指针手感只能接近：各电脑刷新率、垂直同步、缩放和加速曲线不同 | 不同系统 | F34 物理速度换算与速度系数 |
| 网络抖动：Wi-Fi / VPN 明显差于网线 | 物理链路 | 推荐网线直连 |
| 各电脑睡眠和锁屏各自独立，只能联动 | 不同系统 | 防闲置与联动规则（F7） |
| Wayland 需要系统授权，焦点信息依赖 Shell 扩展 | Wayland 安全模型 | 授权令牌、扩展 |
| 管理员窗口需要以管理员运行 CSC | Windows UIPI | 管理员模式安全约束（F29） |
| 已配对主机拥有全部被控端的键鼠 | 产品本质 | 暂停共享、紧急暂停、托盘绿点（F33） |
