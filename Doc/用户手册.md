## 1. 它能做什么

- 用一套键盘鼠标控制多台电脑：鼠标推过屏幕边缘就到了另一台电脑，键盘跟着走。
- 在一台电脑复制文字或图片，在另一台电脑直接粘贴。
- 在一台电脑复制文件，到另一台电脑的文件管理器或桌面按 `Ctrl+V`（或托盘「粘贴其他电脑复制的文件到这里」），文件就存到那个文件管理器当前打开的文件夹（托盘粘贴则存到兜底保存目录）。

它不是“把多台电脑变成一台电脑的多块屏幕”，有些事做不到，见 §15 固有限制。

**名词**：接着键盘鼠标的那台叫**主机**，其他叫**被控端**。

## 2. 安装

### 2.1 系统要求

| 平台 | 要求 |
|---|---|
| Windows 10/11（64 位） | 设置窗需要 **WebView2 Runtime**（多数 Windows 11 自带；没有时从微软官网安装 Evergreen 版） |
| Linux（64 位）GNOME **Wayland** 会话：Ubuntu 24.04 LTS、Ubuntu 26.04 LTS 等（GNOME 46 及以上） | 系统自带的 `xdg-desktop-portal` 与 `xdg-desktop-portal-gnome`；首次使用要允许系统授权并启用 CSC 的 GNOME Shell 扩展（§2.5）；界面需要 WebKitGTK 运行库（包名 TBD） |
| Linux（64 位）**X11** 会话：Deepin/UOS、Ubuntu 24.04 的「Ubuntu on Xorg」等 | 安装 `libx11-6`、`libxtst6`、`libxi6`、`libxfixes3`；界面需要 WebKitGTK 运行库（包名 TBD） |
| KDE Plasma 6（Wayland） | 尽力支持，尚未验证（TBD） |
| Sway、Hyprland 等 wlroots 桌面 | 不支持（缺少所需的系统接口），程序会提示“当前桌面环境不受支持” |

> 说明：Ubuntu 24.04 默认是 Wayland 会话，登录界面仍可选「Ubuntu on Xorg」；从 Ubuntu 25.10 起 GNOME 不再提供 Xorg 会话，26.04 只有 Wayland。CSC 在两种会话下都能用，不需要切换会话。

Debian / Ubuntu / Deepin（X11 会话需要；Wayland 会话一般已自带所需组件）：

```bash
sudo apt install libx11-6 libxtst6 libxi6 libxfixes3
```

### 2.2 获取程序

解压发布包（安装包 MSI / deb / AppImage 计划中，TBD）：

| 平台 | 文件 |
|---|---|
| Windows | `Cross-SystemConnect.exe`（界面）、`Cross-SystemConnect-core.exe`（内核），放在同一目录 |
| Linux | `Cross-SystemConnect`、`Cross-SystemConnect-core`，放在同一目录并 `chmod +x` |

> 所有电脑必须使用 **v2.x**。v2 与 v1.x 不能互连，界面会提示“对端版本过旧，请同时升级”。

### 2.3 网络连接

推荐两台电脑用网线直连，专门给 CSC 用，上网仍走各自的 Wi-Fi：

| 电脑 | 直连网卡 IP | 掩码 | 网关 / DNS |
|---|---|---|---|
| 主机 | 192.168.100.1 | 255.255.255.0 | **不填** |
| 被控端 | 192.168.100.2 | 255.255.255.0 | **不填** |

- 也可以用 USB 网卡加网线、或 USB4 直连。
- 不填网关和 DNS，保证上网流量不走直连线。
- 两边必须在同一个 /24 网段（主机只扫描所选网卡所在的 /24）。

### 2.4 防火墙

放行 `Cross-SystemConnect-core` 的以下端口，**只对直连网卡所在网络放行**（Windows 安装包创建的规则只作用于“专用”和“域”网络，请把直连网卡的网络类型设为“专用”）：

| 端口（默认） | 用途 | 设置项 |
|---|---|---|
| TCP 24900 | 控制连接（键鼠、切换、剪贴板通知） | 控制端口 |
| TCP 24901 | 数据连接（文件、大段文字、图片） | 数据端口 |
| UDP 24900 | 自动发现 | 发现端口 |

> 这三个端口都可以在 **设置 → 网络** 里修改（见 §8.3）。**改了端口后，要在防火墙里放行新端口**（Windows 上建议按程序放行 `Cross-SystemConnect-core.exe`，改端口后不用再改规则）。

Linux（ufw）示例：

```bash
sudo ufw allow in on <直连网口名> to any port 24900:24901 proto tcp
sudo ufw allow in on <直连网口名> to any port 24900 proto udp
```

改过端口时，把上面的端口号换成你设置的控制端口、数据端口（TCP）和发现端口（UDP）。

CSC 默认只在私有地址（如 `192.168.x.x`、`10.x.x.x`）和链路本地地址上监听，不会在公网地址上等待连接（见 设置 → 网络 的“监听地址”）。

### 2.5 Ubuntu（Wayland）首次设置

Wayland 不允许程序随意读取或模拟键盘鼠标，CSC 要经过系统授权：

1. **启用 CSC 的 GNOME Shell 扩展**：首次运行向导（或 设置 → 高级 → 系统集成）点「安装/启用扩展」。安装包版已放好扩展，只需启用。**启用后要注销并重新登录一次**。扩展用来识别文件管理器和全屏程序、提供本机快捷键。
2. **允许授权**：
   - 主机：系统弹出“允许捕获输入”之类的对话框（文字以系统为准），点「允许」。
   - 被控端：第一次被控制时，系统弹出“允许远程交互”对话框，点「允许」。
   - 授权会被记住，以后一般不再询问；系统能否在重启后记住取决于 GNOME 版本（TBD）。
3. 拒绝过授权时，首页会显示红色横幅“系统授权被拒绝”，到 设置 → 高级 → 系统集成 点「重新授权」。
4. GNOME 在被远程控制时，顶栏会显示系统自带的“正在被远程控制”指示，这是正常的。

## 3. 首次运行与选择角色

1. 在每台电脑上运行 `Cross-SystemConnect`（界面）。界面会自动拉起同目录下的内核。
2. 第一次运行会打开向导：
   1. **「这台电脑接着键盘鼠标吗？」** 接着键盘鼠标的那台选 **是** → 主机；其他电脑选 **否** → 被控端。
   2. **选择直连网卡**；「开机自动启动」默认勾选。
   3. （仅 Ubuntu Wayland）**系统授权**（§2.5）。
   4. **添加电脑**：向导最后自动打开“允许新配对”，接着做 §4 配对。
3. 只能有一台主机。如果两台都选了主机，两边都会提示“两台都设为键鼠主机”，不会连接；到 设置 → 高级 → 角色 把其中一台改为被控端即可。

> 只运行内核且没有配置时，默认是被控端，并且不会自己写开机自启。

## 4. 配对

为了防止陌生设备随便弹窗，CSC 只在你主动打开“允许新配对”时才接受配对：

1. **两台电脑都**打开「添加电脑…」：托盘菜单「添加电脑…」，或 设置 → 设备 →「添加电脑…」（首次运行向导最后会自动打开）。窗口有效 **2 分钟**，显示倒计时，可随时点「停止」。
2. 两边连上后，**主机**弹出配对窗，显示对方的计算机名和一个 6 位数字，例如 `482 913`。
3. 在**被控端**的配对窗里输入这 6 位数字，点「确认」。输错有 3 次机会，用完本次配对作废。
4. 回到**主机**，确认名字无误后点 **「配对」**。
5. 你没有在连这台电脑，或名字不对，就点 **「取消」**：可能有别的设备在冒充。
6. 配对成功后，新电脑出现在主机首页的 **“未摆放”** 区，**把它拖进布局格子后才会被控制、收到剪贴板**（§5）。

说明：

- 没有打开「添加电脑…」时，别的电脑发来的配对请求会被直接拒绝，不弹窗。
- 60 秒内没有完成会自动取消；取消后 5 分钟内这台设备（或同一 IP）不会再弹窗。
- 配对一次后，以后自动连接，不再询问。
- 对方重装系统或删除了 CSC 的证书后，需要两边重新打开「添加电脑…」再配对；配对窗顶部会显示红色警告“这台电脑以前配对过，但身份已改变”。确认是你自己重装的再继续。
- **没有配对的电脑收不到你的键盘输入和剪贴板内容。**
- 在 **设置 → 设备** 里可以查看和移除设备，移除后下次连接需要重新配对。

## 5. 屏幕布局

布局只在主机的首页显示：

- 主机固定在中间，周围显示已配对的电脑：已连接的是实心标记，暂时断开的保留位置、显示空心标记。
- 把电脑方块拖到上、下、左、右或四个角之一，和它在桌上的实际位置一致。松开后会吸到最近的空位。
- 暂时断开的电脑保留位置，重连后可以直接穿屏；把另一台电脑拖到它的位置上会把它挤回“未摆放”区。
- **新配对的电脑不会自动摆放**，先出现在画布下方的“未摆放”区；拖进格子后才参与切换和剪贴板。把方块拖回“未摆放”区即可暂时移出布局。
- 方块上的名字是软件里的计算机名，修改它不会改系统的计算机名。
- 当前按“整台电脑”摆放；按每块显示器分别摆放和上下错位对齐计划在以后的版本提供（TBD）。

## 6. 切换与快捷键

### 6.1 切换

- 把鼠标移到有邻居的那条边，**到边后再继续往外推一下**（默认 8 像素）就切过去。沿着边滑动或往回移不会切换。
- 部分触摸板、手写板或远程桌面读不到“继续推”的动作，这时碰到边就会切换。
- 只有对角放了电脑时，角才能穿过去；否则从边的中段穿过。
- 在被控端上，把鼠标推出它的外侧边，就回到主机或到下一台。
- 控制其他电脑时，**主机的鼠标指针会隐藏**；回到主机时，指针出现在与离开处对应的位置。被控端不在使用时也会隐藏它自己的指针（都可在 设置 → 快捷键与切换 关闭）。
- 快速甩过边时，越过的那段距离会带到对面，指针不会“卡”在边上。
- 不同缩放比例（如 150% 与 100%）的屏幕上，指针移动的实际距离保持一致；觉得某台电脑偏快或偏慢，可在 设置 → 设备 调整那台电脑的“指针速度”。
- 滚轮按高精度单位转发，触控板慢慢滚也不会丢；X11 被控端会把细小的滚动累积成一格再滚。
- 多显示器：只有真正露在外面的边才算边；不同分辨率拼接形成的空档不算。
- 在被控端玩全屏游戏等隐藏鼠标的程序时，推到边不会切换，请用热键回到主机。

### 6.2 快捷键

| 功能 | 默认 | 说明 |
|---|---|---|
| 回到主机 | `Ctrl+Alt+/` | 在任何被控端上按下，立即回到主机；这些按键不会发给被控端 |
| 所有电脑一起锁屏 | `Ctrl+Alt+Shift+L` | 在任意一台电脑按下，所有已连接的电脑一起锁屏 |
| 锁定在当前屏幕 | `Ctrl+Alt+Shift+K` | 开/关；开启后推边不会切换（见 §6.4） |
| 紧急暂停被控 | `Ctrl+Alt+Shift+P` | 只在**被控端本地键盘**上有效：立即停止被主机控制，再按一次恢复（§6.9） |

- 快捷键都在 设置 → 快捷键与切换 里修改；录制时会提示与系统、其他程序或常用开发工具（如 JetBrains 的 `Ctrl+Alt+L`）冲突的组合。
- 锁屏联动规则：
  - 你**主动锁屏**（按上面的热键，或在任一电脑按 `Win+L`/系统菜单锁屏）→ 所有电脑一起锁屏，3 秒内只算一次。
  - **主机**闲置超时自动锁屏 → 其他电脑跟着锁屏。
  - **被控端**闲置自动锁屏 → 不影响其他电脑。
- **防熄屏**：你在任何一台电脑上操作时，其他已连接的电脑不会熄屏或闲置锁屏；停止操作 1 分钟后恢复各自的熄屏设置（设置 → 快捷键与切换 →「使用任一电脑时，其他电脑不熄屏」）。
- 可以把锁屏热键改回 `Win+L`，但在 Windows 主机上这个组合由系统处理，会先锁主机，再通知其他电脑。
- 在被控端上单独按一下 `Win`，会正常打开被控端的开始菜单或活动概览。
- 德语、法语等带 `AltGr` 的键盘布局：`AltGr+键`（如输入 `@`）不会被当成 `Ctrl+Alt` 快捷键；录制快捷键时请用左 `Alt`。
- 从 v1.x 升级时，旧热键 `Ctrl+Alt+Home`、`ScrollLock`、`Win+L`、`Ctrl+Alt+L`、`Ctrl+Alt+K` 会自动换成新的默认值（只换一次）。

### 6.3 不会卡键

切换、拔网线、锁屏时，CSC 会自动松开被控端上所有按着的键和鼠标按钮。有键按着时如果断线，被控端 0.5 秒内松开所有键；没有键按着时，1.5 秒内键鼠回到主机。按住一个键时的连续输入由被控端自己产生，网络卡顿不会让字符失控重复。

### 6.4 防止误切换

| 功能 | 怎么用 | 默认 |
|---|---|---|
| 按住键不切换 | 设置 → 快捷键与切换 →「按住此键时不切换」：无 / Ctrl / Shift / Alt。按住该键时推边不会切换 | 无 |
| 锁定在当前屏幕 | 按 `Ctrl+Alt+Shift+K` 或托盘「锁定在当前屏幕」。开启后托盘图标带锁标记，推边不切换；`Ctrl+Alt+/` 仍可回主机。重启程序后自动关闭 | 关 |
| 全屏时不切换 | 前台是全屏程序（视频、游戏、演示）时推边不切换，主机和被控端都适用；热键不受影响。Ubuntu Wayland 上需要启用 CSC 的 Shell 扩展才能判断全屏 | 开 |
| 角落死区 | 距屏幕角落 10 像素以内推边不切换，避免点开始按钮或热角时误切。对角放了电脑时，角落用于切到那台电脑 | 10 像素 |

### 6.5 键盘布局与输入法

- CSC 传的是“按了哪个键”，不是“打了什么字”。打出什么字由**被控端自己的键盘布局和输入法**决定。
  - 两台电脑布局相同（如都是美式）时没有区别。
  - 布局不同时，按同一个键打出的字符按被控端布局。例如被控端是德语布局，按键盘上的 Y 会打出 Z。
- 输入法在被控端使用：在被控端用它自己的快捷键切换中文/英文，候选框也显示在被控端。主机的输入法不受影响。
- `Win` 对应 Linux 的 `Super`；`Ctrl`、`Alt`、`Shift` 左右分别对应。右 `Alt` 在被控端是否作为 `AltGr`，由被控端布局决定；主机上的 `AltGr` 不会误触发 `Ctrl+Alt` 快捷键。
- 需要交换按键（例如让被控端的 `Ctrl` 和 `Super` 互换）时，可在配置文件 `keyboard.remap` 里设置（设置窗不提供）。

### 6.6 大写锁定与数字锁定

- 切到被控端时，被控端的 CapsLock、NumLock、ScrollLock 会自动调成和主机一样。
- 在被控端打开或关闭了大写锁定，回到主机后主机也会跟着变。
- 不想同步时，在 设置 → 快捷键与切换 里关闭「同步锁定键」。

### 6.7 主机休眠、关机或断网时

- **被控端的本地键盘鼠标任何时候都能用**，CSC 不会占用它们。
- 主机休眠、关机、重启前会先把键鼠交还，被控端上不会留下按着的键。
- 被控端托盘会显示主机状态：已连接 / 主机休眠 / 主机失联 / 重连中（断开时还会弹通知，可在 设置 → 通知与语言 里关闭）。
- 主机唤醒或网络恢复后自动重连，不需要任何操作。

### 6.8 锁屏、登录界面和 UAC（Windows）

- 当前版本**不能**控制 Windows 被控端的锁屏、登录界面、UAC 提示和 `Ctrl+Alt+Del` 界面（系统的“安全桌面”）。
- 被控端进入这些界面时，键鼠会自动回到主机，主机首页在这台电脑上显示「安全桌面」，此时推边不会切过去；回到桌面后自动恢复。
- 请用被控端本地的键盘鼠标解锁或确认 UAC。
- Linux 被控端的锁屏一般可以通过 CSC 输入密码解锁（不同桌面环境的情况 TBD；GNOME Wayland 锁屏时系统可能暂停远程输入，TBD 实测）。

### 6.9 暂停共享与托盘绿点

- **暂停共享**：托盘菜单或首页「暂停共享」。暂停期间不切换、不同步剪贴板、不接受新的文件传输；正在控制被控端时键鼠立即回到本机。托盘图标带暂停标记。重启程序后自动恢复共享。
- **被控端紧急暂停**：在被控端本地键盘按 `Ctrl+Alt+Shift+P`（或被控端托盘「暂停共享」），主机立即失去对它的控制，主机首页这台电脑显示“已暂停”。再按一次恢复。
- **托盘绿点（连接/被控状态）**：已连接时，主机与被控端的托盘图标右下角都显示绿色圆点（常亮）。指针在本机时绿点保持常亮；本机正在被主机控制时，**仅被控端**绿点闪烁（主机从不闪烁）。未连接时不加绿点。屏幕上不再弹出「Controlled」文字叠层。
- 已配对的主机可以操作被控端上的一切，就像有人坐在那台电脑前；只和你信任的电脑配对，离开时可暂停共享。

## 7. 剪贴板与文件粘贴

### 7.1 文字和图片

- 在一台电脑复制，另一台电脑直接 `Ctrl+V`。
- 文字最大 15 MB（可在 设置 → 剪贴板与文件 里调小，范围 1–15 MB）；超过上限不同步，会弹出系统通知。
- 图片（截图、复制的图片）以 PNG 传输，可在 设置 → 剪贴板与文件 里关闭。
- 默认复制后立即通知其他电脑；如果不希望内容在你切过去之前就发出，可把「发送时机」改为“只在切到该电脑时发送”。暂停共享时不发送。
- 较大的文字和图片在**你粘贴的时候**才传输，粘贴可能要稍等一下；网络断开时 3 秒后放弃并提示。
- 只同步给已配对、并且摆在布局里（不在“未摆放”区）的电脑。
- 密码管理器（如 KeePassXC）复制的密码不会同步。
- Linux X11 会话如果没有 XFixes 扩展，剪贴板变化检测与图片同步不可用；Ubuntu Wayland 经系统剪贴板接口同步（首次授权见 §2.5）。
- **带格式的文字**（网页、Word、LibreOffice 里复制的内容）会同时同步格式（HTML、RTF），粘贴到支持格式的程序里保留格式，粘贴到记事本等则是纯文字。可在 设置 → 剪贴板与文件 关闭「同步格式」。
- 同时复制了文字和图片（如表格）时，同步文字和格式，不同步图片。

### 7.2 文件

1. 在电脑 A 的资源管理器/文件管理器里复制文件或文件夹（`Ctrl+C`）。此时不会传输，也不会改其他电脑的剪贴板。
2. 到电脑 B，打开要存放的文件夹，在**文件管理器窗口或桌面**上粘贴：
   - Windows：按 `Ctrl+V`。
   - Linux（X11 和 Wayland）：按 `Ctrl+V`，或用右键菜单「粘贴」。
3. 文件存到 B 上**这个文件管理器当前打开的文件夹**（在桌面上粘贴就存到桌面），B 上弹出进度窗，显示“保存到：…”。

存放位置的规则：

| 情况 | 存到 |
|---|---|
| Windows 资源管理器打开的是普通文件夹 | 该文件夹 |
| Windows 资源管理器在“此电脑”、库、网络等虚拟位置 | 兜底保存目录（进度窗会注明） |
| Linux 文件管理器（Nautilus、Dolphin、Thunar、Caja 等）或 Ubuntu 桌面 | 粘贴的那个文件夹 |
| 托盘菜单「粘贴其他电脑复制的文件到这里」 | 兜底保存目录 |

注意：

- 在 B 的记事本、终端、浏览器等其他窗口按 `Ctrl+V`，是普通的粘贴，不会传文件，粘出来的是 B 原来的剪贴板内容。
- Linux 上的原理：文件管理器获得焦点时，CSC 临时把剪贴板换成“占位文件”，你粘贴后 CSC 找到它落在哪个文件夹，再把真正的文件传进去；离开文件管理器时恢复原来的剪贴板。所以在文件管理器里粘贴后会先看到一个很小的占位文件，随即被真正的文件替换。Ubuntu Wayland 上需要启用 CSC 的 Shell 扩展。
- 之后任何电脑上又复制了别的东西（文字、图片或文件），之前复制的文件记录就作废。复制记录 30 分钟后也会失效。
- 两台被控端之间也能这样复制粘贴，由主机中转。
- **兜底保存目录**：拿不到当前文件夹时使用，默认是桌面；高级用户可以在配置文件里设置 `file_transfer.receive_dir`（设置页只显示，不能修改）。
- 收到的文件：Windows 上会标记为“来自其他电脑”（打开可执行文件时系统会提示）；Linux 上存到桌面的文件会去掉可执行权限。都可在 设置 → 剪贴板与文件 关闭。

### 7.3 进度窗与重名

- 进度窗只在接收文件的电脑上出现：进度、速度、剩余时间、保存到哪里、取消、打开所在位置。完成的条目保留 30 秒。
- 已有同名文件或文件夹时，在进度窗里逐项选择：**跳过 / 保留两者 / 替换**（默认保留两者，多项时有「全部」按钮），点「继续」开始。
  - 保留两者：命名为「原名 (1).扩展名」「原名 (2).扩展名」…
  - 替换：先写临时文件，校验通过才覆盖，失败时原文件不受影响。

### 7.4 传输细节

- **断点续传**：传输中网络断开时，进度窗显示“等待重连”；30 分钟内重连会从断点继续。源文件在此期间被修改则重新传。
- **大量小文件**：会打包传输，进度同时显示文件数和大小。
- **保留的信息**：文件修改时间总会保留；Linux 之间保留权限（如可执行）；Windows 之间保留隐藏、只读属性。所有者、权限列表等不保留。
- **空间检查**：开始前检查剩余空间，不够时提示需要多少、还剩多少，不会写一半。U 盘是 FAT32 时，4 GB 以上的文件无法存放，会单独提示。
- **文件名自动调整**：Windows 不允许的名字会自动改，进度窗列出“原名 → 新名”，完成通知注明改了几项：

| 情况（复制到 Windows） | 调整 |
|---|---|
| 含 `< > : " \| ? *` | 换成 `_` |
| 叫 `CON`、`NUL`、`COM1` 等保留名 | 后面加 `_`，如 `CON_.txt` |
| 以 `.` 或空格结尾 | 去掉后加 `_` |
| 同一文件夹里只差大小写（如 `Readme` 与 `readme`） | 后一个改成 `readme (1)` |
| 路径超过 260 个字符 | 照常保存，但部分程序可能打不开，会提示 |
| 名字超过 255 字节（Windows、Linux 都适用） | 截短并保留扩展名 |

### 8.3 修改网络端口

一般不需要改。只有默认端口被其他程序占用、或公司网络有要求时才改。

1. 打开 **设置 → 网络**，修改控制端口、数据端口或发现端口，范围 1024–65535。
2. 输入时会立即检查，出现下列错误时「保存」按钮不可用：
   - “控制端口和数据端口不能相同”
   - “端口必须在 1024–65535 之间”
   - “端口已被其他程序占用”（会注明是哪个端口、TCP 还是 UDP）
3. 点「保存」。如果有正在进行的文件传输，会先提示“将中断正在进行的传输”。
4. 保存后程序自动换到新端口并重新连接其他电脑，**不需要重启程序**。键鼠会先回到主机，重连后即可继续使用。
5. **在防火墙里放行新端口**（§2.4）。

注意：

- **控制端口、数据端口**每台电脑可以不同，其他电脑会自动知道你用的是哪个端口。
- **发现端口**所有电脑必须相同；只改了一台的话，彼此会发现不到（之前连过的电脑仍会按上次的地址尝试重连）。
- 如果直接编辑配置文件把控制端口和数据端口写成同一个值、或写了超出范围的数字，程序会显示 **“网络配置无效”**，不会连接任何电脑；到 设置 → 网络 改正后即可恢复。
- 启动时端口被其他程序占用，也会显示“网络配置无效（端口已被占用）”，程序每 10 秒自动重试一次。

### 8.4 通知

连接、断开、配对请求、传输完成或失败、错误（如磁盘空间不足、网络配置无效、版本不兼容）会弹系统通知。每类通知都可以在 设置 → 通知与语言 里关闭（配对请求除外）。同一类通知 5 秒内只弹一次。Windows 解压版能否弹通知需要开始菜单快捷方式（TBD）。

### 8.5 手动添加电脑与多网卡

- **跨网段、VPN、IPv6**：自动发现只找同一个 /24 网段里的电脑。其他情况在主机的 设置 → 设备 →「手动添加的电脑」里填对方的 IP（如 `10.8.0.5`）、IPv6 地址（如 `fe80::1%eth0`）或主机名，对方改过控制端口时一起填上。
- **网卡模式「自动」**：有线网卡和“自动模式可用的 Wi-Fi”列表里的 Wi-Fi 都可用于连接。网线拔掉时，会自动改用这些网络重连，不需要重新配对。通过 Wi-Fi 或 VPN 时延迟会高于网线直连。
- 自动模式**不会使用公共网络**（Windows 中网络类型为“公用”的网络、不在列表里的 Wi-Fi），也只在私有/链路本地地址上监听；在 设置 → 网络 点「添加当前 Wi-Fi」把家里或办公室的 Wi-Fi 加入列表（Linux 需要 NetworkManager）。

### 8.6 语言

设置 → 通知与语言 → 语言：跟随系统 / 简体中文 / English。修改后设置窗、托盘菜单和通知立即切换。

### 8.7 配置文件

配置文件位置：Windows `%APPDATA%\Cross-SystemConnect\config.json`，Linux `~/.config/cross-systemconnect/config.json`。本机证书 `identity.crt`、`identity.key` 也在该目录（私钥文件只有本用户可读；选择“系统密钥库”时私钥改存 Windows DPAPI / GNOME 密钥环），**私钥不要拷到别的电脑**。Ubuntu Wayland 的系统授权记录保存在同目录 `portal-tokens.json`。

## 9. 版本与更新

- 所有电脑最好使用同一版本。版本不兼容时两边都会提示双方的版本号，请升级到同一版本。
- 版本不同但兼容时（例如 0.2.0 与 0.2.1）可以正常使用，设置 → 设备 会建议升级。
- CSC **不会自动下载或安装更新**。在 设置 → 关于与更新 点「检查更新」可以查看是否有新版本并打开下载页面（下载地址 TBD）。版本信息带数字签名，签名不对时显示“更新信息签名无效”并忽略；下载页只会打开官方域名。
- 更新步骤：托盘「退出」→ 替换程序文件（或运行新安装包）→ 重新启动。配置和配对记录会保留。

## 10. 诊断信息与崩溃

- 程序异常退出时，托盘程序会自动把内核重新启动；短时间内反复崩溃会停止重启并通知。
- 崩溃信息保存在日志目录下的 `crash` 文件夹（最多 5 份）。
- 反馈问题时，请在 设置 → 隐私与诊断 →「导出诊断信息」生成 zip 文件一起提供。导出前会列出包含的文件。诊断包包括日志、崩溃摘要、去掉私钥的配置、状态和系统信息；**不包含**私钥、系统授权记录、剪贴板内容、文件内容和按键。
- Windows 崩溃转储（`.dmp`）可能含有内存中的剪贴板、文件名等敏感数据，**默认不放进诊断包**；只有你勾选「包含崩溃转储」并确认后才包含，只发给你信任的人。

## 11. 测量性能（高级）

1. 在两台电脑的 设置 → 隐私与诊断 里都打开「测量模式」（不用时请关闭）。
2. 在主机上运行：
   ```bash
   Cross-SystemConnect-core --bench latency --peer <对方计算机名> --samples 11000
   Cross-SystemConnect-core --bench throughput --peer <对方计算机名> --size 4GiB
   Cross-SystemConnect-core --bench smallfiles --peer <对方计算机名> --files 10000
   ```
3. 结果显示在终端，并保存为日志目录下的 `bench-<时间>.csv`。延迟给出 P50、P99 等数值；建议在网线直连、两台都接电源、没有其他传输时测量，每项测 3 次。

方法细节见[架构设计](架构设计.md) §12.15。

## 12. 隐私声明与杀毒软件

**隐私声明**

- CSC 只在你配对过的电脑之间传输键盘鼠标操作、剪贴板和文件，数据不经过任何服务器。
- 不收集使用统计，不上传任何信息。唯一的外网访问是你手动点「检查更新」（或打开了启动时检查）时，读取一次版本信息。
- 日志里不记录你按了哪些键、剪贴板内容、文件内容和配对码；默认日志级别下也不记录文件名。
- 本机证书私钥 `identity.key` 只保存在本机配置目录，文件只有你自己可读；也可以改存系统密钥库（设置 → 隐私与诊断）。不要拷到别的电脑。
- 设置界面只把其他电脑发来的名字、文件名当作纯文字显示，不会执行其中的代码。
- 更新信息经数字签名验证；CSC 内核本身不访问外网。
- 崩溃转储默认不放进诊断包（§10）。

**杀毒软件 / 企业安全软件报警**

CSC 需要键盘钩子和模拟输入，这和一些恶意软件的行为相似，可能被误报。

1. 确认程序来自官方渠道：Windows 程序有数字签名（右键 → 属性 → 数字签名），并可与发布页的 `SHA256SUMS` 核对。
2. 向杀毒软件厂商提交误报（Microsoft Defender 可通过 Microsoft Security Intelligence 网站提交）。
3. 需要时把程序加入白名单。Windows Defender（管理员 PowerShell）：
   ```powershell
   Add-MpPreference -ExclusionProcess "C:\<安装目录>\Cross-SystemConnect-core.exe"
   ```
   加白名单会降低该程序的防护，请只对确认来源的程序这样做。
4. 企业环境请联系 IT 部门，按数字签名证书或文件哈希加入 EDR 白名单。

## 13. 卸载与数据清理

**安装包版**：在系统的“应用”/软件管理里卸载。卸载时会询问是否删除配置和数据，默认保留（便于重装后不用重新配对）。

**解压版 / AppImage**：

```bash
Cross-SystemConnect-core --uninstall           # 删除自启项和临时文件
Cross-SystemConnect-core --uninstall --purge   # 同时删除配置、证书、配对记录和日志
```

然后删除程序文件。也可以在 设置 → 隐私与诊断 →「清除所有数据并退出」（可选择保留配对记录）。

| 内容 | Windows 位置 | Linux 位置 | 默认 |
|---|---|---|---|
| 自启项 | 注册表 `HKCU\...\Run`、计划任务 | `~/.config/autostart/cross-systemconnect.desktop`、`~/.config/systemd/user/cross-systemconnect-core.service` | 删除 |
| 防火墙规则 | 安装包创建的规则 | 你自己添加的 ufw 规则需手动删除 | 删除（安装包版） |
| 配置、证书、配对记录 | `%APPDATA%\Cross-SystemConnect\` | `~/.config/cross-systemconnect/` | 询问，默认保留 |
| 日志、崩溃信息 | 程序目录 `log.txt`、`%APPDATA%\Cross-SystemConnect\` | 程序目录 `log.txt`、`~/.local/state/cross-systemconnect/` | 询问，默认保留 |
| 临时文件 | `%TEMP%\Cross-SystemConnect\` | `$XDG_RUNTIME_DIR` 下的 `cross-systemconnect-core.*`、`csc-paste/` | 删除 |
| GNOME Shell 扩展、系统授权记录 | — | `~/.local/share/gnome-shell/extensions/csc-shell@<域名 TBD>/`（deb 版在 `/usr/share/gnome-shell/extensions/`）、`portal-tokens.json` | 删除 |
| 私钥（系统密钥库） | DPAPI 加密文件 | GNOME 密钥环中的条目 | 随配置一起询问 |
| 未完成传输的 `.csc-part` 文件 | 各存放位置 | 各存放位置 | 删除 |
| 收到的文件 | 桌面等 | 桌面等 | **不删除** |

卸载后，其他电脑上仍保留这台电脑的配对记录，可在它们的 设置 → 设备 里移除。

## 14. 常见问题排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 两台电脑互相看不到 | 不在同一 /24 网段；主机选错网卡；防火墙拦截；发现端口不一致 | 检查直连 IP 和掩码；在 设置 → 网络 选对网卡，并把 Windows 直连网络设为“专用”；放行控制/数据端口（默认 TCP 24900/24901）和发现端口（默认 UDP 24900）；确认各电脑发现端口相同；点「刷新」 |
| 被控端提示“主机休眠”或“主机失联” | 主机休眠、关机或网络断开 | 唤醒主机或检查网线，恢复后自动重连；期间被控端本地键鼠可正常使用 |
| 主机首页显示某台电脑「安全桌面」，切不过去 | 该 Windows 电脑在锁屏、登录或 UAC 界面 | 用那台电脑本地键鼠解锁或确认（§6.8） |
| 打出的字符和键帽不一样 | 两台电脑键盘布局不同 | 把被控端的键盘布局改成和键盘一致（§6.5） |
| 切过去后大小写状态不对 | 关闭了「同步锁定键」 | 打开 设置 → 快捷键与切换 → 同步锁定键 |
| 推边不切换（全屏或角落） | 前台是全屏程序；在角落死区内；按住了“不切换”键；开启了锁定在当前屏幕 | 用热键切换；离角落远一点推；松开按键；按 `Ctrl+Alt+Shift+K` 取消锁定 |
| 提示“磁盘空间不足” | 存放位置所在的盘不够 | 清理空间后重新复制粘贴（`Ctrl+C` / `Ctrl+V` 或托盘粘贴） |
| 收到的文件名和原来不同 | 名字在 Windows 上不合法，被自动调整 | 查看进度窗中的“原名 → 新名”（§7.4） |
| 连不上其他网段 / VPN 里的电脑 | 自动发现只找同一 /24 | 手动添加对方地址（§8.5） |
| 提示对端版本不兼容 | 两边版本差太多 | 升级到同一版本（§9） |
| 内核反复重启后停止 | 程序连续崩溃 | 导出诊断信息反馈（§10） |
| 显示“网络配置无效” | 配置文件中控制端口与数据端口相同、端口超出 1024–65535，或端口被其他程序占用 | 到 设置 → 网络 改正；或关闭占用端口的程序（程序每 10 秒自动重试） |
| 改了端口后连不上 | 防火墙没放行新端口；只在一台电脑上改了发现端口 | 放行新端口；把所有电脑的发现端口设成相同的值 |
| 提示“对端版本过旧” | 一边是 v1.x | 所有电脑升级到 v2.x |
| 提示“两台都设为键鼠主机” | 两台都选了主机 | 把其中一台改为被控端 |
| 提示“配对码不对” | 输错了；或连上的不是你想配的电脑 | 核对主机显示的数字重新输入（3 次机会）；名字不对就在主机点「取消」 |
| 没有弹出配对窗 / 提示“对方没有打开添加电脑” | 两边没有都打开「添加电脑…」；2 分钟已过期；5 分钟内取消过 | 两边都点「添加电脑…」再连；取消过的等 5 分钟 |
| 配对窗显示“身份已改变”红色警告 | 对方重装或删除了证书；也可能有设备冒充 | 确认是自己重装的再配对，否则「取消」 |
| 被控端重装后连不上 | 证书变了 | 两边打开「添加电脑…」重新配对；必要时在 设置 → 设备 里移除再配对 |
| 配对成功但推边不切换、剪贴板不同步 | 新电脑还在“未摆放”区 | 在主机首页把它拖进布局 |
| 主机推边不切到某台、显示“已暂停” | 对方按了紧急暂停或开启了暂停共享 | 在那台电脑上取消暂停（再按 `Ctrl+Alt+Shift+P` 或托盘取消勾选） |
| 什么都不同步、托盘带暂停标记 | 本机开启了「暂停共享」 | 托盘取消勾选「暂停共享」 |
| 推到边不切换 | 那条边没有摆电脑；推得不够；对端尺寸未知；被控端在玩全屏游戏 | 检查布局；再多推一点或调小 `edge_push_px`；用热键回主机 |
| 一碰边就切换 | 读不到原始位移（触摸板、远程桌面，或 Linux 缺 `libxi6`） | Linux 安装 `libxi6` |
| Linux X11 被控端指针不动 | 缺 `libx11-6` / `libxtst6` | 安装运行库 |
| Ubuntu Wayland 被控端指针不动，首页显示“需要系统授权”或“系统授权被拒绝” | 没有允许“远程交互”授权，或拒绝过 | 设置 → 高级 → 系统集成 →「重新授权」，在系统对话框点「允许」（§2.5） |
| Ubuntu Wayland 主机推边不切换 | 没有允许输入捕获授权 | 同上 |
| 提示“Shell 扩展未启用”；Wayland 上 `Ctrl+V` 不传文件、全屏判断无效、本机快捷键无效 | CSC 的 GNOME Shell 扩展没装、没启用或版本不匹配 | 设置 → 高级 → 系统集成 →「安装/启用」，然后**注销重新登录** |
| 提示“当前桌面环境不受支持” | 在 Sway、Hyprland 等桌面上运行 | 改用 GNOME（Wayland 或 X11）或其他 X11 桌面 |
| 控制不了 Windows 上的管理员窗口 | 普通权限无法向管理员窗口注入 | 开启「以管理员权限运行」 |
| UAC 弹窗、登录界面控制不了 | 安全桌面不支持 | 用本机键鼠操作 |
| 设置窗打不开（Windows） | 没有 WebView2 Runtime | 安装 WebView2 Runtime |
| `Ctrl+V` 没有传文件 | 不在文件管理器/桌面里按；之后又复制过别的；超过 30 分钟；Windows 上用的是右键粘贴；暂停了共享 | 在文件管理器或桌面按 `Ctrl+V`（Linux 也可右键粘贴），或用托盘「粘贴其他电脑复制的文件到这里」 |
| 文件存到了桌面而不是当前文件夹 | 资源管理器在“此电脑”、库等虚拟位置；或用了托盘粘贴 | 打开一个普通文件夹再粘贴；进度窗会注明使用了兜底保存目录 |
| Linux 文件管理器里出现一个很小的文件后消失 | 这是 CSC 的占位文件，随即被真正的文件替换 | 正常现象；传输失败时占位会被删除并提示 |
| 在文本框里 `Ctrl+V` 粘出的是旧内容 | 复制文件不会改其他电脑的剪贴板 | 这是设计行为 |
| 大段文字粘贴很慢或失败 | 粘贴时才传输；网络断开 | 等待；检查网线 |
| 密码没有同步 | 密码管理器内容按设计不同步 | 手动输入 |
| 想跨屏拖文件 | 跨屏拖拽已取消 | 在源端复制文件，到目标端文件管理器或桌面按 `Ctrl+V`，或用托盘「粘贴其他电脑复制的文件到这里」（§7） |
| 有按键像是一直按着 | 异常情况 | 切回主机再切过去，或按一下该键；仍有问题请附日志反馈 |
| 被控端在你使用主机时熄屏或锁屏 | 关闭了防熄屏；或公司策略强制锁屏（TBD） | 打开 设置 → 快捷键与切换 →「使用任一电脑时，其他电脑不熄屏」 |
| 两台电脑指针速度感觉不同 | 缩放、加速曲线不同 | 设置 → 设备 调整那台电脑的指针速度 |
| 按了 `Ctrl+Alt+L` 没反应 / 和 IDE 冲突 | v2 默认锁屏热键是 `Ctrl+Alt+Shift+L` | 按新热键，或在 设置 → 快捷键与切换 修改 |
| 提示“更新信息签名无效” | 网络被篡改或下载源异常 | 稍后重试；从官方发布页核对 |
| 杀毒软件报毒 | 键盘钩子被误报 | 确认程序来自官方并已签名，加入信任 |
| 想看日志 | — | 内核：程序目录 `log.txt`（不可写时 Windows `%APPDATA%\Cross-SystemConnect\Cross-SystemConnect.log`，Linux `~/.local/state/cross-systemconnect/Cross-SystemConnect.log`）；界面：配置目录 `ui.log`。排错时可在 设置 → 高级 → 日志 把级别调到 debug |

## 15. 固有限制

CSC 让多台电脑共用一套键鼠，但它们仍然是各自独立的电脑，以下是做不到或只能接近的事（详见 [PRD](PRD.md) §10）：

| 限制 | 说明与替代办法 |
|---|---|
| 窗口不能拖到另一台电脑，也不能横跨两台电脑 | 每台电脑有自己的窗口系统 |
| 键盘跟着指针所在的电脑走 | 不能指针停在 B、打字到 A；需要时用「锁定在当前屏幕」 |
| 文件不能跨屏拖放 | 跨屏拖拽已取消；用复制粘贴（§7） |
| 剪贴板不是同一个 | 大内容在粘贴时才传输，粘贴可能稍等 |
| `Ctrl+Alt+Del`、UAC、登录界面只能本机操作；触控板多指手势由主机系统处理 | 系统安全设计 |
| 键盘布局和输入法各自独立 | 两端设相同布局 |
| 指针手感只能接近 | 各电脑刷新率、缩放和加速曲线不同；可调每台速度 |
| Wi-Fi / VPN 明显不如网线 | 推荐网线直连 |
| 睡眠和锁屏各自独立，只能联动 | 见 §6.2 锁屏规则与防熄屏 |
| Ubuntu Wayland 需要系统授权，部分功能依赖 Shell 扩展 | 见 §2.5 |
| 控制管理员窗口需要以管理员运行 CSC | Windows 的权限隔离 |
| 已配对的主机可以操作所有被控端 | 只和信任的电脑配对；暂停共享、紧急暂停、托盘绿点（§6.9） |
