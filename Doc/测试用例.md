# Cross-SystemConnect 测试用例

> 文档版本：v2.0 · 对应软件 v2.0.0（未发布）· 协议版本 2
> 相关文档：[PRD](PRD.md) · [架构设计](架构设计.md) · [界面设计](界面设计.md) · [构建发布流程](构建发布流程.md)

## 1. 说明

- **编号**：`T-<模块>-<序号>`。来源标记：**[原]** = v1.1 已有覆盖（v1.1 共 73 个单元测试，`cargo test --workspace` 通过），按 v2 设计更新；**[新]** = 优化方案新增的 36 项。
- **类型**：单元（`cargo test`）、集成（两进程或两实例，可在同一台机器或 CI 容器内）、真机（Windows + Linux 实机，网线直连）、模糊（cargo-fuzz）。
- **优先级**：P0 = 每次提交/发布必过；P1 = 发布前必过；P2 = 发布前抽测。
- **默认环境**：主机 Windows 11（`192.168.100.1/24`）、被控端 Linux（`192.168.100.2/24`；Ubuntu 24.04 GNOME Wayland 与 Deepin/Ubuntu X11 各跑一轮，标注“X11”或“Wayland”的用例只在对应会话跑）、千兆网线直连、两端已配对（除配对用例外）。
- **Linux 会话矩阵**：Ubuntu 24.04 LTS（GNOME 46，Wayland 默认，仍可选 Xorg）、Ubuntu 26.04 LTS（GNOME 50，仅 Wayland）、Deepin（X11）。
- 对应的 PRD 功能编号写在模块标题后。
