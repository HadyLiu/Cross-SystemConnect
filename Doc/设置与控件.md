# Cross-SystemConnect 设置与控件

> 与 `crates/csc-ui` 当前实现对齐。只列功能、配置字段与 IPC，不含视觉/布局设计。  
> 界面线框与视觉规范见 [界面设计.md](界面设计.md)；配置与 IPC 细节见 [架构设计.md](架构设计.md)。

改动后一般自动 `save_config`；改角色或端口会顺带 `rescan`。

---

## 1. 壳与托盘

| 控件 | 作用 |
|---|---|
| 侧栏 8 项导航 | 切页：首页、剪贴板与文件、快捷键与切换、网络、通知与语言、隐私与诊断、高级、关于 |
| 页头「刷新」 | `rescan` + 刷新状态 |
| 页头消息 | 保存 / 操作结果提示 |
| 侧栏底连接状态 | 只读：已连接 / 未连接 |

**托盘菜单**：设置 · 暂停/继续共享 · 退出。  
Windows 双击托盘、Linux 单击托盘亦可打开设置。

启动参数：`--open-settings` 打开设置；`--background` 仅托盘（自启项使用）。

## 2. 首页

| 区块 | 控件 | 配置 / IPC |
|---|---|---|
| 配对确认（条件显示） | 确认 / 取消 | `resolve_peer`（trust / reject） |
| 运行状态 | 计算机名 | `cfg.name` |
| | 键鼠主机 / 被控端 | `cfg.role` |
| | 连接 / 对端 / 活动屏幕 | 只读 status |
| | 暂停/继续共享 | `set_sharing_enabled` |
| 主机状态 | 换一组 | `roll_home_code` |
| | 网卡 / IP 列表（点选） | `cfg.search_address` |
| | 本机六位配对码 + 倒计时 | 只读 `homeCode` / `homeCodeUntil` |
| 屏幕位置（仅主机） | 3×3 摆放格 | `cfg.screens` |
| | 添加对方配对码（六位） | `pair_offer`（输满即发） |
| 已信任 | 每台指针速度 | `cfg.pointer.peers` |
| | 移除 | `forget_peer` |

角色差异：屏幕位置与「添加对方配对码」仅主机显示；边缘切换规则仅主机可改；配对确认条出现在被输入码的那一端。

## 3. 剪贴板与文件

| 区块 | 控件 | 配置字段 |
|---|---|---|
| 剪贴板 | 启用剪贴板共享 | `clipboard.enabled` |
| | 文本 / 图片 | `clipboard.text` / `clipboard.image` |
| | 发送时机：立即 / 只在切到该电脑时 | `clipboard.push_mode` |
| | 文字上限 MB（1–15） | `clipboard.max_inline_mb` |
| 文件传输 | 启用 | `file_transfer.enabled` |
| | 复制文件后 Ctrl+V 传输 | `clipboard.files` |
| | 单文件上限 MB | `file_transfer.max_size_mb` |
| | 限制传输速度 | `file_transfer.limit_speed` |
| | 限速 MiB/s | `file_transfer.max_speed_mibs` |
| | 断点续传 分钟 | `file_transfer.resume_window_min` |

## 4. 快捷键与切换

| 区块 | 控件 | 配置字段 | 备注 |
|---|---|---|---|
| 快捷键 | 锁定屏幕 | `hotkeys.lock_screen` | 文本编辑 |
| | 回到本机 | `hotkeys.return_to_server` | 仅主机 |
| | 锁定在当前屏幕 | `hotkeys.lock_to_screen` | |
| | 紧急暂停 | `hotkeys.emergency_pause` | |
| 边缘切换 | 按住不切换 | `switch.block_modifier` | 被控端只读提示；none / ctrl / shift / alt |
| | 全屏程序时不切换 | `switch.block_when_fullscreen` | |
| | 有人使用时尽量不让电脑休眠 | `power.keep_peers_awake`（并写 `gui.prevent_sleep`） | |
| | 指针速度 | `pointer.speed` | |

## 5. 网络

| 控件 | 配置字段 |
|---|---|
| 控制端口 | `control_port`（默认 24900） |
| 数据端口 | `data_port`（默认 24901；不可与控制端口相同） |
| 发现端口 | `network.discovery_port`（各机须相同） |
| 启用心跳 | `network.heartbeat_enabled` |
| 心跳间隔 ms | `network.heartbeat_ms` |

---

## 6. 通知与语言

| 控件 | 配置字段 |
|---|---|
| 对端连接 | `notify.connect`（默认关） |
| 断开、主机休眠或失联 | `notify.disconnect` |
| 文件传输 | `notify.transfer` |
| 错误 | `notify.errors` |
| 主题：深色 / 浅色 | `gui.theme`（`dark` / `light`，默认 `dark`） |
| 界面语言：简体中文 / English / 跟随系统 | `gui.language`（`zh-CN` / `en-US` / `auto`，默认 `zh-CN`） |

配对请求总会弹出，不受通知开关影响。

## 7. 隐私与诊断

| 控件 | 配置 / IPC |
|---|---|
| 隐私说明 | 只读文案 |
| 测量模式 | `diagnostics.bench_enabled` |
| 导出诊断信息 | `export_diagnostics` |
| 重置设置（保留配对） | `reset_data(keepPairing=true)` |
| 重置设置并清除配对 | `reset_data(keepPairing=false)` |

## 8. 高级

| 区块 | 控件 | 配置 / 行为 |
|---|---|---|
| 窗口 / 托盘 | 启动后驻留托盘 | `gui.auto_hide` |
| | 关闭设置后继续驻留 | `gui.close_to_tray` |
| | 开机自启 | `gui.launch_at_login`（自启项带 `--background`） |
| 日志设置 | 级别 debug / info / warn / error | `log.level`（同步 `log_level`） |
| | 写入文件 | `log.to_file` |
| | 路径 + 浏览… / 默认 | `log.file`（空 = 程序目录 `log.txt`） |
| 日志 | 只读文本 + 刷新 | `get_logs` |
| 进入 / 离开命令 | 进入本机时执行 + 命令行 | `enable_enter_command` / `enter_command` |
| | 离开本机时执行 + 命令行 | `enable_exit_command` / `exit_command` |

## 10. 传输进度窗

独立窗口，由 status.`transfers` 推送打开。

| 控件 | IPC / 行为 |
|---|---|
| 进度、速率、剩余时间、状态 | 只读推送 |
| 取消 | `cancel_transfer` |
| 打开 / 打开文件夹 | 系统打开路径 |
| 关闭 | `dismiss_transfer` |
| 重名：跳过 / 保留两者 / 替换（可全部）· 继续 | `resolve_conflict` |
